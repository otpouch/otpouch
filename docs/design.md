# 口袋令牌官网设计

面向需要管理多个双重验证账号的人，让访客了解口袋令牌的微信小程序与独立 App。小程序现在可用，iOS、Android App 开发中；当前通过正式版小程序码开始使用。

## 视觉与结构

- 采用编辑式的黑白工具风格：炭黑 `#1C1C1E`、白色 `#FFFFFF`、浅灰 `#F2F2F7`，正文灰 `#636366`。红色只用于演示验证码即将过期的状态。
- 英文使用本地打包的 Geist Variable，中文使用 PingFang SC / Microsoft YaHei，不依赖远程字体服务。
- 桌面首屏采用文字与可交互小程序演示的非对称布局；功能区以一个搜索示意配合操作说明，Agent 区使用炭黑底；最后展示 FAQ 与再次获取入口。
- 手机端使用单列布局与折叠导航，保留完整演示、FAQ 和使用入口。支持减少动态效果的系统偏好。

## 组件

`LandingPage → Header / AppDemo / Platforms / Features / AgentSection / FAQ / Footer / GetAppDialog`

## 状态与产品边界

- 演示支持按发行方、账号、备注搜索、清空、空结果、复制成功与失败、倒计时换码、页面切换。
- 弹窗具备焦点管理、键盘 Escape 关闭、小程序码缺失和图片加载失败状态。
- 正式版小程序码由用户从微信账号设置下载并提供，原图保存在 `public/miniprogram-code.jpg`。官方素材不裁剪、不改色、不重新生成；配置见 `lib/site-config.ts`。用于其他产品时替换为自己的入口，素材范围见 `../BRAND_ASSETS.md`。
- 首屏、平台区、获取弹窗、FAQ 与页面元数据一致标注 iOS、Android App“开发中”；未开放下载，不提供商店、安装包或 TestFlight 邀请链接。
- 平台区桌面并排、手机纵向展示；获取弹窗限制可视高度并可滚动，保留二维码图片加载失败、复制成功/失败、键盘关闭和焦点管理。
- 数据都为示例，不请求真实账号或 MCP 服务。网站不收集凭证或备份。
- 文案应与已验证的产品功能一致；涉及网络使用、备份、回收站和 Agent 授权的说明需要与对应发布版本核对。

## 自检约束

1. 不用虚构评价或用户数量建立可信度，使用可操作的产品演示。
2. 不把二维码占位伪装成可扫描入口。
3. 不宣传源码尚未实现的安全或离线能力。
4. 不为手机缩小整页，使用独立断点布局。
5. 使用可聚焦控件、语义标题和可访问的弹窗/折叠组件，隐藏不可见的复制反馈。
